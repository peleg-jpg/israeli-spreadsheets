# israeli-spreadsheets

Generate Excel spreadsheets with Israeli tax calculations, VAT, NIS formatting, and Hebrew-labeled financial templates. Use when user asks about Israeli tax spreadsheets, NIS-formatted Excel files, VAT calculations, salary slip templates, arnona estimators, or Israeli accounting worksheets. Covers 2025 tax brackets, Bituach Leumi rates, and openpyxl RTL configuration.

## Install

Will be installable via `npx peleg-skills install israeli-spreadsheets` once the CLI ships.
Manual install: clone this repo into `~/.claude/skills/israeli-spreadsheets/`.
